# Reflection

**- What did you ask Copilot to help you build? How did you break down the problem?**
I asked Copilot to help me build a mircoblogging text-based website/app, similar to X and Threads in a way. I began by telling Copilot to build the foundation with simple features like a feed with a like feature. Then gradually built the profile, posting, and discover functions of the project. It's not fully fleshed out but it mostly does what it needs to.

**- How did your approach to asking questions change as you worked?**
I got a bit more specific and added examples as to what I wanted to Copilot, it did help in making the bot understand what it had to do better than not adding any examples.

**- What parts of the development process with GitHub Copilot surprised you?**
When testing how the website looks on a desktop or mobile, it took me to what the site would look like and updated in real-time. I found that very interesting and surprising. 

**- What did you learn about the technology you used that you didn't know before?**
I learned about a few features on VS that I wasn't aware of before since Copilot used them, such as taking a screenshot inside VS of the display. 

**- What would you do differently if you had to build this again?**
Probably be a little more specific with certain features so I won't have to tell Copilot to fix it up later after there was a mistake or miscommunication.
